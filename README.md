# 💻 DBMS and SQL — 365 Days of Learning

Welcome to my **365 Days of DBMS and SQL** journey! 🚀

Starting on **29 October 2026**, I am committing to learning database management systems from scratch, practising SQL every day, and strengthening my problem-solving skills through hands-on challenges.

This repository documents my daily progress, SQL solutions, database concepts, and key learnings throughout the journey.

## 🎯 Goals

- Build a strong foundation in DBMS concepts.
- Learn SQL from scratch and practise it consistently.
- Solve SQL problems on LeetCode.
- Understand relational databases and database design.
- Master joins, subqueries, CTEs, and window functions.
- Learn normalization, indexing, transactions, and query optimization.
- Develop practical database skills relevant to software development and AI/ML roles.
